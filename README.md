# Maths Attax

A football maths game for Shayan and Aanav.

## What's in this folder
- index.html: the whole game
- manifest.webmanifest: the app name, icon and full-screen settings
- sw.js: lets the game work offline once it has been opened
- icons/: the home-screen icon

## Updating the game
1. Replace index.html with the new version.
2. In sw.js, change VERSION (for example maths-attax-v1 to maths-attax-v2).
3. Upload both files to GitHub. Vercel republishes in about a minute.
